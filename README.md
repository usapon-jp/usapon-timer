# うさぽんタイマー

制作や事務作業の時間をやさしく積み上げて振り返る、スマホ向けの作業記録タイマーです。

## Features

- 10分 / 25分 / 50分タイマーと自由計測
- 作業カテゴリ選択
- 作業ログ、成果物メモ、気分、成果物数の記録
- 日ごと・月ごとの売上入力
- 月間作業時間、売上、実質時給、カテゴリ別時間の分析
- ポイント報酬
- 衣装の解放と着せ替え
- localStorage保存

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
